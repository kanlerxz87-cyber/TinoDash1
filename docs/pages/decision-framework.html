Decision Framework (Pre-Commitment)

Agree in writing on what would make the household choose each path before private figures arrive. This prevents reverse-engineering the answer from one projection.

Use this page as a decision record. Write the decision and date next to each item when a choice is made. Keep the filled version in a private, non-public location; do not commit PII.
