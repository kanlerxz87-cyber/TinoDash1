Privacy & Data Handling

Personal information privacy is top priority. This repo/site uses anonymized placeholders and rounded values. No names, exact addresses, ZIP codes, parcel/APN IDs, account numbers, or unrounded personal financial records are published.

Rule: Do not commit PII to git, issues, PRs, screenshots, or site pages. If PII is discovered, remove it from files and scrub git history before pushing/publication.

Git History Scrub Checklist

  1. Search tracked files and git history for PII patterns (names, addresses, ZIPs, exact parcel IDs, account numbers).
  2. If found, remove from working tree and rewrite history using git filter-repo or equivalent on a clean clone.
  3. Force-push rewritten history only with explicit coordination; invalidate caches/forks where possible.
  4. Rotate any exposed credentials/secrets immediately (not applicable to normal property data, but mandatory for secrets).
  5. Document scrub in COORDINATION.md and Flagged for Review.

Safe Handling Rules

  • Use ranges/rounded figures in public artifacts.
  • Keep appraisals, tax returns, trust documents, leases, and account statements in private storage only.
  • When sharing with advisers, use secure channels and redact unnecessary identifiers.
  • Before every commit, run a PII grep audit.

Privacy is a process, not a one-time filter. Re-audit before every publish.
