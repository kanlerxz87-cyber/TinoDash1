Repository Privacy & Git History Containment Protocol

  • Strict Public-Repo Anonymization: No personal names, street addresses, APNs, emails, or trust names appear anywhere in tracked files or commit history on this branch.
  • $10-Increment Rounding Gate: Automated CI check (scripts/privacy-audit.mjs) verifies every user-asset currency figure in data/properties.json is divisible by 10.
  • Independent Historical Branches Containment: If an earlier session branch exists in GitHub's remote branches with pre-rounding user figures, repository owners should (a) prune stale non-main branches via git push origin --delete <old-branch>, (b) verify repository visibility (Private recommended once private tax bills/APNs are added offline), and (c) contact GitHub Support to clear cached reflogs if any sensitive branch was once public.
