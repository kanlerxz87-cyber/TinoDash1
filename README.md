# Decision Desk

A static, privacy-first planning guide for a potential trust transfer and an already-owned property. Open `index.html` locally or host as a static site. No build dependencies, analytics, external scripts, storage, or data collection. The stress lab uses hypothetical index units, not household figures or a historical backtest.

This public guide is not a substitute for legal, tax or investment advice. See the flagged items and official source links in the site. Do not commit private inputs, parcel identifiers, documents or appraisal data. Rounding does not ensure anonymity.
