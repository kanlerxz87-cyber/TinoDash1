How to review these

  1. Read each row's why column; if it does not affect a decision, mark it declined.
  2. Promote any Blocking item on the Questions page first — those gate the ranking of paths.
  3. Record the acceptance date next to the item (per the standing instruction: write the decision and the date).
  4. After accepting, re-run the model and note in Flagged whether the recommendation moved.
